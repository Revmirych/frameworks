# Workshop Booking System

Система управления бронированием мастер-классов на Django и Django REST Framework.

## Технологический стек
- Django 6.0.5
- Django REST Framework 3.17.1
- Django REST Framework Simple JWT
- SQLite (по умолчанию) или PostgreSQL

## Установка и запуск

### Локальный запуск
1. Перейдите в директорию проекта:
   ```bash
   cd workshop_project
   ```
2. Примените миграции:
   ```bash
   python manage.py makemigrations
   python manage.py migrate
   ```
3. Создайте суперпользователя (опционально):
   ```bash
   python manage.py createsuperuser
   ```
4. Запустите сервер:
   ```bash
   python manage.py runserver
   ```

### Запуск с Docker
1. В корневой директории проекта запустите:
   ```bash
   docker-compose up --build
   ```

## API Endpoints

### Аутентификация
- `POST /api/token/` - Получить токен доступа и обновления
- `POST /api/token/refresh/` - Обновить токен доступа

### Пользователи
- `POST /api/users/` - Регистрация нового пользователя

### Мастер-классы
- `GET /api/workshops/` - Получить список мастер-классов
- `GET /api/workshops/<id>/` - Получить детали мастер-класса
- `POST /api/workshops/` - Создать мастер-класс (только админ)
- `PUT /api/workshops/<id>/` - Обновить мастер-класс (только админ)
- `DELETE /api/workshops/<id>/` - Удалить мастер-класс (только админ)

### Бронирования
- `GET /api/bookings/` - Получить свои бронирования (только авторизованный пользователь)
- `POST /api/bookings/` - Забронировать мастер-класс (только авторизованный пользователь)
- `DELETE /api/bookings/<id>/` - Отменить бронирование (только владелец)

## Функциональность
- Регистрация и авторизация пользователей через JWT
- Просмотр списка и деталей мастер-классов (публичный доступ)
- Создание, редактирование, удаление мастер-классов (только админ)
- Бронирование мастер-классов (только авторизованные пользователи)
- Просмотр и отмена своих бронирований
- Проверка вместимости мастер-класса
- Защита от бронирования прошедших мастер-классов
- Защита от дублирования бронирований
