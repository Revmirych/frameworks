Домашнее задание 1
Темы:

Архитектура и структура проекта в Django.
Работа с базами данных и ORM в Django.
CRUD и REST API в Django.

Цель задания: закрепить навыки проектирования архитектуры веб-приложения, разработки серверной логики, работы с базами данных, организации REST API и подготовки проекта к деплою на разных технологических стеках.

Инструменты для выполнения: Python, Django, Django REST Framework, FastAPI, PostgreSQL / SQLite, Django ORM / TypeORM, Postman.
